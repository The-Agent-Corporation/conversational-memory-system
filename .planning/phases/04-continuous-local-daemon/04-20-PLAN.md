Current diagnosed boundary:
- `/usr/bin/osascript` attributes `display notification` to Script Editor bundle `com.apple.ScriptEditor2`.
- `display notification` returns no Notification Center presentation acknowledgement; subprocess exit zero proves only that AppleScript accepted/executed the command.
- The durable degraded-episode latch in SourceStateMachine remains the one-shot authority and notification failure remains best-effort after the guarded state commit.

Required receipt semantics:
- `capable`: the local command path is available.
- `commandAccepted`: the injected command runner returned exit code zero.
- `presentation`: always `unverified` because this adapter has no presentation callback.
- `identity`: the exported stable display name and bundle identifier the user must authorize.
</interfaces>
