From src/sync/materialization/sync-materializer.ts (~lines 447-480):
- `emitLocalSyncOperation` reads the frontier on one connection and commits the outbox row on another; the domain effect was already committed by the caller. On `commitLocalSyncOperation` returning STATE_CHANGED or EQUIVOCATION the receipt is discarded (`Promise<void>`), silently dropping the sync outbox row.
- Producers calling it: box-reviewer.ts, proposal-reviewer.ts, source-lifecycle-service.ts, mutation-application.ts, codex-importer.ts.

From src/mcp/mutation-application.ts (line 218):
- `return plan?.kind === expectedKind ? plan : plan;` — both branches return `plan` (dead guard). Should return `undefined` on mismatch.

From src/sync/secrets/macos-keychain-secret-store.ts (~lines 289-294) and macos-keychain-helper.swift (~lines 198-207):
- For a `read`, the helper writes the secret frame to fd 6 inside handle(...) then serve() writes the result frame to fd 4; the Node runner reads the result frame first (readFrame(controlOut)) then the secret frame (readFrame(secretOut)). A secret larger than the OS pipe buffer deadlocks.
