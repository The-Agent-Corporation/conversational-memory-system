## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local authoritative mutation → outbox | A crash must not separate domain authority from the operation queued for synchronization. |
| decrypted remote operation → local memory | Remote origin is untrusted and must pass person/scope/tombstone/state checks atomically. |
