## Trust Boundaries
| Boundary | Description |
|---|---|
| durable outbox → relay | Exact sealed bytes, membership, retries, and acknowledgements cross the network boundary. |
| malicious relay → local apply | Relay may tamper, replay, omit, reorder, rollback, fork, duplicate, or flood gaps. |
| daemon configuration → production network | Endpoint, TLS, ephemeral token, and limits select the actual HttpSyncRelay. |
| full archive → MCP profile | Device trust must not become agent retrieval authority. |
