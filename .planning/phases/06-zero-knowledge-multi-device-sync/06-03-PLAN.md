## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sync services → OS secret store | Private key material leaves process memory only for protected local storage. |
| TypeScript → native helper | Process invocation can leak through argv/stdout/stderr or logs if not constrained. |
