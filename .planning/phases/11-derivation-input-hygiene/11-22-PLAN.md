Summary record (`src/domain/types.ts:104-129`) — the fields that discriminate:
  id, personId, summaryText, sourceTurnRanges[], sourceCanonicalEventIds?: string[],
  origin?: "host_session" | "historical_bootstrap", createdAt, model, promptVersion, state, version
There is NO hygiene-rule-version field on a Summary. `origin`, `createdAt`, and `model` are the
available provenance discriminators.

Derivation input construction, verbatim (`src/daemon/contraction-runner.ts:400-414`):
  const sourceEvents = events.slice(windowStart, windowEnd);              // FULL raw window = provenance
  const rawTurns = sourceEvents.map((event, offset) => turnFromEvent(event, span.hostSessionId, windowStart + 1 + offset));
  const derivable = sourceEvents.slice(0, derivationEnd - windowStart);   // text-only narrowing
  const sourceTurns = derivationContents(derivable).map(({ index, content }) => ({ ...rawTurns[index]!, content }));
  const draft = await this.summarizer.summarize({ span, sourceTurns });

So `sourceCanonicalEventIds` IS the full raw window, and re-running `derivationContents` over the events
those ids name reproduces the summarizer's input — except at a trailing withheld open run, where
`derivationEnd < windowEnd`. Flag any offender whose span ends inside a tool run as
`reconstruction-approximate` rather than classifying it confidently.

The second derivation seam (11-CONTEXT.md "Both contraction paths, one shared module"):
  src/compaction/pre-compactor.ts:39 — `derivationContents(turnsInSpan)`
  src/integrations/hermes/adapter.ts — the live agent bridge
A summary with `origin: "host_session"` came through a different seam than one with
`origin: "historical_bootstrap"`.

Known by-design behavior (`derivation-hygiene.ts:165-173`): a tool segment of exactly ONE event is
emitted VERBATIM, arguments included — `if (segment.entries.length === 1) return segment.entries[0];`.
This is 11-CONTEXT.md's locked decision ("a single isolated tool call keeps its existing text") and
ROADMAP SC3 forbids `[Tool call:` text only "from collapsed runs". An offender of this shape is
therefore compliant with the requirements as written and non-compliant only with Plan 11-13's stricter
self-authored must_have.

Live corpus: clone with `cp -c`, open `{ readOnly: true }` or via `SqliteStore` on the CLONE only.
