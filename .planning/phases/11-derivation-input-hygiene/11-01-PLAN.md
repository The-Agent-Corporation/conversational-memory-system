<objective>
Create `src/topic/derivation-hygiene.ts` — the ONE shared, pure, deterministic module that classifies a
canonical event / turn into `conversational | tool_activity | synthetic_injected` and turns an ordered
window of events into the derivation content that feeds summarization. Then rewire
`11-hygiene-sim.ts` to import this module so the measured-target re-run validates production code
rather than a parallel copy.

Purpose: Every other plan in this phase imports this module. RESEARCH's top anti-pattern is
re-deriving classification in more than one place (`explain-service` guessing a different rule than
the one that actually fired). This plan makes that structurally impossible: one rule table, one
collapse function, one version constant.
Output: New pure module + unit tests + a sim that exercises the real module.
</objective>
