|----------|-------------|
| MCP client (agent) → memory_search / memory read tools | An agent reads these results as authoritative memory |
| vector index → semantic recall (Phase 14) | Vector rows outlive their summaries unless tombstoned |
| subject expansion → whole canonical events | Expansion returns raw event content, the highest-fidelity disclosure surface |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-11-25 | Information Disclosure | Subject expansion walking `sourceSummaryIds` into a superseded summary and returning its canonical events | mitigate | Predicate added to the recursive fail-closed condition; test exercises the recursive walk |
