<objective>
Close GAP-11-G: a rebuild regenerates 1,330 of the 26,643 anchors Plan 11-18 deleted, all carrying raw
`[Tool call: …]` text. Measured on the Plan 11-25 rehearsal clone; the live corpus was never touched.

Two independent defects produce this, and BOTH are fixed here. Fixing only the first would stop these
1,330 while leaving the second as a silent hole for the next caller.

**Defect 1 — the rebuild path has no hygiene gate at all.** `src/daemon/contraction-runner.ts:590`
defines its OWN local `anchorsForTurn`. It does not import `AnchorDetector` and therefore never runs the
GAP-11-D forward gate. Its only protection is `survivingDerivationIndices` (line 469), which still
implements the PRE-reversal SC1 rule — `if (currentRun.length === 1) survivors.add(...)` — that Plan
11-24 reversed in `derivationContents`. An isolated tool call survives, reaches `anchorsForTurn`, and is
anchored from raw text. The contract comment at lines 247-254 still states the pre-reversal behavior
verbatim ("conversational events and ISOLATED single tool calls") and is now wrong.

**Defect 2 — the forward gate is blind to `eventKind`.** `AnchorDetector.detectForTurn` gates on
`drivesTopicLabel({ content: turn.content, role: turn.role })`. `Turn` has no `eventKind` field and
`turnFromEvent` does not carry it in metadata, so `classifyEvent` falls through to its content-prefix
branch (`eventKind === null && content.trimStart().startsWith(TOOL_CALL_PREFIX)`). Demonstrated:

```
tool_call kind, content w/o prefix | full=tool_activity  gate=conversational anchorMinted=true
tool_call kind, content w/ prefix  | full=tool_activity  gate=tool_activity  anchorMinted=false
role=tool,      content w/o prefix | full=tool_activity  gate=tool_activity  anchorMinted=false
```

Row 1 is an event the STORE classifies `tool_activity` and the GATE classifies `conversational`. The
asymmetry is already documented at `src/storage/sqlite-store.ts:1341` — the prune's classification input
is deliberately a superset of the gate's — but it was recorded as safe-because-superset, and the
converse (the gate admitting what the prune would delete) was never closed.

Purpose: REQ-052 / REQ-053.
Output: both paths gated, both pinned by regression tests, ADR 0051 amended.
</objective>
