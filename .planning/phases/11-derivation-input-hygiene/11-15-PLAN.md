<objective>
Close GAP-11-B: `dedupeRankedMemory` → `isAnchorCoveredBySummary` (`src/retrieval/memory-retriever.ts:319-349`)
performs a full anchor × summary cross-product in which the expensive work runs first and the cheap
rejections run last. Measured at ~48,900 pairs/sec against the live corpus, one frozen recall query
extrapolates to 4.5 hours; Plan 11-13 needs two full 12-query runs, so SC7 evidence is unreachable today.

The fix is two behavior-preserving changes — hoist the per-summary normalization out of the per-anchor
loop, and reorder the conjunction so `sharesBox`/`sharesThread` short-circuit before the substring
search. `normalizedMemoryText`, `sharesBox`, and `sharesThread` are pure and side-effect-free, so the
selected set is provably unchanged.

Purpose: this is on the path of every host injection request today, not just the probe. The correctness
bar (identical selection) matters more than the speedup, so it is pinned by a test written and passing
against unmodified HEAD *before* the implementation changes.
Output: the fix, a differential equivalence test, and a deterministic benchmark.
</objective>

```typescript
interface RankedMemory {                       // *export as a type in Task 1
  kind: "summary" | "anchor" | "trace" | "box_context";
  id: string;
  text: string;
  score: number;
  tokenCount: number;
  canUseStub: boolean;
  scoringMethod: "keyword overlap" | "vector similarity";
  summaryId: string | null;
  summaryIds: string[];
  traceId: string | null;
  sourceTurnRanges: TurnRange[];               // TurnRange has a threadId field
  boxIds: string[];
}

function dedupeRankedMemory(ranked: RankedMemory[]): RankedMemory[];   // *export in Task 1
function isAnchorCoveredBySummary(anchor: RankedMemory, summaries: RankedMemory[]): boolean;
function sharesBox(left: RankedMemory, right: RankedMemory): boolean;
function sharesThread(left: RankedMemory, right: RankedMemory): boolean;
function normalizedMemoryText(value: string): string;  // value.toLowerCase().replace(/\s+/g," ").trim()
```

Shapes that constrain the fixtures (from `rankAnchor` and `rankSummary`, lines 422-505):
```
anchors  -> sourceTurnRanges is ALWAYS [];  boxIds is [] or exactly one id (anchor.boxId)
summaries-> sourceTurnRanges and boxIds come straight off the Summary row (either may be empty)
```
Consequence, and the reason the reorder alone is not the whole fix: for an anchor with no box,
`sharesBox` returns true and `sharesThread` reduces to "the summary has any turn ranges" — so the
guards reject only a subset of pairs. The dominant win is the hoisted normalization.
