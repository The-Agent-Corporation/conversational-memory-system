<objective>
Produce the evidence the SC7 judgement needs, and run the live prune under owner authorization. Plan 07
could run mechanical probes but could not judge semantic correctness, and full-corpus probes were
impractical because retrieval loaded every summary per query — Plan 11-10 fixed that. This plan builds the
repeatable probe, captures the three-way comparison (pre-hygiene backup / current corpus after the state
filter / current corpus after the prune), and gates the destructive live step on the owner.

Purpose: SC7 needs a before/after that a human can read. The judgement itself is Plan 11-14.
Output: probe harness, frozen query set, `11-RECALL-PROBE.md`, and a pruned live corpus.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| probe process → the 4.6 GB pre-phase11 backup | The last recoverable copy of the pre-hygiene corpus; SqliteStore writes on open |
| owner authorization → irreversible live deletion | The gate; an unverified affirmation must not open it |
| probe output → SC7 judgement | If the probe is not reproducible, the sign-off is unfalsifiable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-48 | Tampering | The backup silently migrated and rewritten by opening it with SqliteStore | mitigate | Every backup read goes through a `cp -c` copy; acceptance criterion asserts the original's mtime is unchanged |
| T-11-49 | Repudiation | A sign-off recorded for work that was never performed (the exact Plan 07 failure mode) | mitigate | Task 2 requires independent database assertions before recording authorization; a bare affirmation is explicitly insufficient |
| T-11-50 | Tampering | Live prune executed without authorization or without a verified backup | mitigate | Task 3 is conditional on Task 2's recorded authorization; the command's own `--confirm-backup` gate is a second independent check |
| T-11-51 | Information Disclosure | Probe artifacts containing personal conversation text committed to the repository | mitigate | Record summary ids, flags, scores, and elapsed times in full; quote packet text only in short excerpts sufficient to judge relevance, and redact anything the owner flags at the Plan 11-14 checkpoint |
| T-11-52 | Tampering | A drifting query set making before/after incomparable | mitigate | `11-RECALL-QUERIES.md` is frozen and committed before the first run; git ordering is an acceptance criterion |
| T-11-53 | Denial of Service | The `before` run against 135,366 unfiltered summaries never finishing | mitigate | Per-query elapsed printing, no abort timeout, and the run happens on a disposable copy so it can be restarted freely |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No packages installed in this plan |
</threat_model>
