# GAP-11-E — Tool-call text still reaches injection packets via summaries

**Status:** open (blocks Phase 11's SC7)
**Found:** 2026-07-27, by the `after-anchor-prune` run of the frozen 12-query recall probe (Plan 11-18)
**Owner decision:** not yet made — this gap is being raised, not closed.

## What it is

GAP-11-D established that anchors were injecting raw `[Tool call: ...]` text and closed that path
(forward gate `4d17978`, live prune `fe9adcb`). Tool-call text in injection packets fell from 10/12
queries to **4/12**, and no query's top-ranked memory is a raw tool-call payload any more.

The four survivors — **Q1, Q3, Q4, Q10** — all have **non-empty `sourceSummaryIds`** (2, 3, 2, 3
respectively). Per the discriminator established in `11-RECALL-PROBE.md`'s diagnostic, only
`rankSummary` sets a non-empty `summaryIds`; `kind: "anchor"` and `kind: "box_context"` items produce
an empty list. So the winning memory in all four cases **is summary-derived**.

The derivation-hygiene rebuild (Plans 11-01/11-02) reduced tool-call text in summaries — the corpus
audit that motivated Phase 11 measured 38% of summaries containing verbatim `[Tool call:` argument
text, and the rebuild collapsed tool runs into activity descriptions — but did not eliminate it.

## Evidence

| | containsToolCallText | containsHarnessText |
|---|---|---|
| `before` (pre-hygiene backup, 135,366 summaries) | 9 / 12 | 1 / 12 |
| `after-filter` (hygiene rebuild + GAP-11-A state filter) | 10 / 12 | 0 / 12 |
| `after-anchor-prune` (GAP-11-D closed) | **4 / 12** | 1 / 12 |

Surviving queries and their `sourceSummaryIds` counts: Q1 (2), Q3 (3), Q4 (2), Q10 (3).

## Why this is not GAP-11-D reopened

GAP-11-D was an *unfiltered derivation path* — anchors were created with no hygiene gate at all and
stored `turn.content` verbatim. That path is now gated forward and pruned backward, with no anchors of
class `tool_activity` or `synthetic_injected` remaining in the live corpus.

This gap is different in kind: summaries **did** pass through the hygiene classifier, and tool-call
text survived anyway. That points at the collapse rules or the summarizer's input selection, not at a
missing gate. The fix is therefore not "apply the same predicate somewhere new."

## Open questions a fix must answer first

1. **Which rule is leaking?** Is the residual text surviving `collapseText`, or entering via a
   summarizer input path that `derivationContents` does not filter, or is it in older summaries the
   rebuild did not regenerate? Determine this before proposing a change.
2. **Is a rebuild sufficient?** `rebuild-derivations` exists and is the natural remediation if the
   current rules would produce clean summaries from the same events. If the rules themselves leak, a
   rebuild reproduces the leak and is wasted work on a 4.6 GB corpus.
3. **Are the four queries hitting the same root cause or several?** Four queries is a small enough
   set to inspect individually rather than generalize from.

## Two anomalies to resolve alongside (they may change the numbers above)

1. **Harness text went 1/12 → 0/12 → 1/12.** Q2 regained harness text after the anchor prune. Leading
   hypothesis: the anchor previously winning Q2 was pruned, exposing a harness-text summary beneath —
   meaning the 0/12 was an anchor masking a summary, not a fix. Unconfirmed.
2. **The probe's harness detector may under-count.** Q12's `after-anchor-prune` preview is literally
   `<task-notification> <task-id>...` — visible harness scaffolding — yet `containsHarnessText`
   reports false. If the detector does not recognise `<task-notification>`, the harness column is
   optimistic in **all three runs**. Check the detector before drawing conclusions from the harness
   column.

## Reusable assets

`11-RECALL-QUERIES.md` (frozen) and `11-recall-probe.ts` are byte-unchanged and reusable as the
acceptance evidence for any fix. The corpus is now fast enough to iterate on: the full 12-query set
runs in ~6.5 minutes (388,816.5 ms), down from ~25 minutes pre-GAP-11-B.

## Recommendation

Do not fold this into Phase 11's SC7 sign-off as a caveat. Phase 11 delivered what it can deliver:
the anchor path is closed and measured. This is a scoped, well-evidenced follow-on with a frozen
acceptance test already built — it should be planned on its own, after question 1 above is answered
by investigation rather than assumption.
