<objective>
Build `memory rebuild-derivations` — a resumable, idempotent, checkpointed full re-derivation of a
person's summaries under the current hygiene rule version, modeled directly on Phase 10's
`backfill-embeddings-command.ts` and on `HistoricalBootstrapper`'s drain loop.

Purpose: REQ-054 and SC5. 59% of summaries disappear and the survivors' text changes, so a selection
predicate buys nothing — the locked decision is a FULL rebuild. The command owns no derivation logic: it
bumps the contraction job's generation, rewinds `earliestAffected` to the first event, and drives the
existing `ContractionRunner`, whose non-resume path already runs the full `DerivationInvalidator`
closure over summaries, anchors, boxes, proposals, and traces.
Output: New command module + registry entry + SC5 integration tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI process → 5 GB live derivation store | This command rewrites every summary for a person; a partial or non-idempotent run is the phase's largest correctness risk |
| running process → SIGKILL | A kill mid-rebuild must leave a resumable, non-duplicating state |
| command → canonical_events | Read-only. The command must never delete or mutate a canonical event (D-1) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-14 | Tampering / destructive action | A full rebuild over a live 5 GB corpus leaving duplicated or orphaned summaries | mitigate | The command drives only `drainSlice`, whose non-resume path runs the full `DerivationInvalidator` closure with `preserveIds`; SC5 tests assert supersession (not deletion), no duplicate windows, and no orphaned vectors |
| T-11-15 | Tampering | Canonical events deleted or mutated during rebuild | mitigate | Command has no write path to `canonical_events`; `grep -c "deleteCanonicalEvents\|saveCanonicalEvent"` in the new module must be 0 |
| T-11-16 | Denial of Service | Rebuild restarting from zero on every invocation, never finishing on a 292k-event corpus | mitigate | Generation is bumped only when a rebuild is not already in flight; the in-flight branch resumes from the durable checkpoint; "idempotent rerun" test asserts zero work after completion |
| T-11-17 | Elevation of Privilege | Rebuilding another person's derivations from a caller with narrower authority | mitigate | Foreground authority is constructed for the exact `personId` and `drainSlice` rejects any mismatch (contraction-runner.ts:83-89); `getPerson` gate fails loud for unknown persons |
| T-11-18 | Information Disclosure | Vectors surviving for superseded summaries and being returned by future semantic recall | mitigate | `deleteSummaryVectors` called per slice for superseded summary ids; asserted in the "no orphans" test |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No packages installed in this phase |
</threat_model>
