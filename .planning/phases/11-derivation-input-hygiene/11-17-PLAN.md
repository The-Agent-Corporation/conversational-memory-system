## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator invocation → deletion | A single flag separates a report from an irreversible 25k-row delete |
| command → store | The command may request, never authorize, a deletion |
| backup claim → reality | A `--confirm-backup` path is an assertion that must be verified on disk |
