<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI process → 4.6 GB live derivation store | A wrong invocation destroys derivations irreversibly except by rebuild |
| `--apply` flag → irreversible deletion | The gate between reporting and destroying |
| command → canonical_events / turns / anchors | Read-nothing, write-nothing; D-1 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-41 | Tampering / destructive action | An operator running the command expecting a report and destroying 87,727 rows | mitigate | Dry-run is the default; deletion requires an explicit `--apply`; test (a) asserts a zero row delta |
| T-11-42 | Tampering | Applying with no recoverable backup | mitigate | `--confirm-backup` gate with `statSync` existence/type/size checks; tests (b) and (c) |
| T-11-43 | Denial of Service | A referenced summary at the head of the cursor wedging the loop forever | mitigate | Cursor advances past skipped ids to the highest id in the batch; idempotency test (g) would hang otherwise |
| T-11-44 | Tampering | Interrupted prune leaving a half-consistent store | mitigate | Per-batch atomic commits plus live-state re-query; test (f) compares against an uninterrupted run |
| T-11-45 | Elevation of Privilege | Pruning a person the operator did not name | mitigate | `personId` bound in options and rechecked inside every commit; unknown person fails loud (test (i)) |
| T-11-46 | Tampering | Revivable (`stale`) memory destroyed as collateral | mitigate | Candidate query returns superseded rows only; test (h) asserts stale survival in every variant |
| T-11-47 | Repudiation | Silent skipping, so an operator believes the corpus is clean when referenced rows remain | mitigate | `skippedByReason` in the result and in every progress line; test (e) |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No packages installed in this plan |
</threat_model>
