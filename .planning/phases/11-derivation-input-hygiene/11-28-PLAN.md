<objective>
Close GAP-11-H: Plan 11-24's line-anchored `matchesEmbedded` fixed embedded scaffolding but created a
false-positive class — **a trailing sentinel after real content now condemns the whole event.**

`[SILENT]` is a response sentinel meaning "emit nothing". An event that IS the sentinel is scaffolding.
An event that is real agent reasoning ENDING in the sentinel is content, and the current rule discards it:

```
{ id: "silent-sentinel", test: (c) => matchesEmbedded(c, markerFor("silent-sentinel")), roles: ["assistant"] }
```

Owner decision 2026-07-28: fix the rule, then prune 330 (not 350). The 20 affected anchors carry real
reasoning — "Confirmed — the McCay email was already processed fully…", "All 12 Roscoe verification tasks
are currently `awaiting_owner` — waiting on Aaron's decision", "PID 89914 is not alive. Per decision rule
A, respond silently." Under `hygiene-rules/v1` these classified conversational, correctly.

**Counted blast radius, measured on the live corpus before this plan was written** (assistant-role events
containing a `[SILENT]` line):

| shape | count | after the fix |
|---|---:|---|
| pure sentinel — residue empty once sentinel lines are removed | **2,784** | stays `synthetic_injected` |
| trailing after real prose | **123** | becomes `conversational` |
| starts with the marker but has residue | **0** | n/a — the ambiguous case does not occur |

So the fix moves exactly 123 events of 292,407. Verify this count independently before changing code; if
your measurement disagrees, STOP and report rather than proceeding against a stale number.

Purpose: REQ-053 (synthetic classification) / REQ-054 (rule version bump).
Output: a narrowed `silent-sentinel` rule, `hygiene-rules/v4`, both sides pinned by tests.
</objective>
