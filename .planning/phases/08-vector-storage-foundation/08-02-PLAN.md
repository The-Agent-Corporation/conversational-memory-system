## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller-authorized (personId, allowedScopeIds) → SQL candidate scan | Storage tier enforces person/scope boundary in the WHERE clause before scoring |
| stored BLOB row → decoded Float32 vector | A persisted (possibly stale-model) row is decoded back into a numeric vector |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure | SqliteStore.findNearestSummaries | mitigate | `person_id = ?` in WHERE + scope `.every` filter run before cosine; topK applied to filtered set only (D-06, Pitfall 1); cross-scope fixture test asserts no leakage |
| T-08-02 | Tampering (accidental) | getSummaryVector BLOB decode | mitigate | unpackFloat32Vector validates byteLength against stored `dimensions` and throws (D-03, Pitfall 3) |
| T-08-03 | Denial of Service | version-2 migration on ~3.5GB DB | accept | Additive `create table if not exists` + one index only; no scan/rewrite of summaries; runs inside runSchemaMigrations' single transaction (SC5) |
| T-08-SC | Tampering | npm/pip/cargo installs | accept | No packages installed (D-02 rejects sqlite-vec); Package Legitimacy Gate N/A |
