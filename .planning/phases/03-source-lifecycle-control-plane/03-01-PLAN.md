# Plan 03-01: Source Lifecycle Control Plane

## Objective

Create the durable control plane required before a local daemon may continuously read history sources.

## Tasks

1. [x] Add person-owned source grants and append-only lifecycle audit events to memory stores.
2. [x] Register approval before import and enforce active grants at the command boundary.
3. [x] Add explicit revocation and confirmed source deletion with derived-memory invalidation.
4. [x] Add bounded redacted quarantine records and deterministic replay controls.
5. [x] Add person and allowed-scope filters to retrieval and tests proving isolation.
6. [x] Run focused tests, full suite, typecheck, smoke harness, and diff checks.

## Verification

- Synthetic source histories only.
- Approval mismatch and revoked-source rejection tests.
- Source deletion preserves unrelated sources and native fixtures.
- Quarantine never stores unredacted secrets or tool-result payloads.
- Retrieval cannot cross person or scope boundaries.
