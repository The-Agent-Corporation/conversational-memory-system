## Bounded Wave 0 scope rationale

This plan intentionally owns the dependency lock, one shared synthetic fixture, and all eight contract modules as a single Wave 0 unit. It creates no production MCP implementation; the test modules share `tests/mcp/fixtures.ts` and must compile together against the same pinned SDK generation. Splitting the files would add cross-plan fixture ownership and sequencing without reducing implementation context, while the three tasks remain bounded to dependency installation, read-contract scaffolding, and mutation/transport-contract scaffolding.
