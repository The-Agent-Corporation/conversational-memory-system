| T-09-02 | Information Disclosure | env.allowRemoteModels network flag | mitigate | true is set in exactly one function with a finally restore to false; TransformerEmbedder never sets it — runtime embed paths cannot reach the network (REQ-040/D-04) |
| T-09-09 | Tampering | wrong-dtype (quantized) file shipped | mitigate | manifest hard-excludes all quantized .onnx variants; only fp32 model.onnx is vendored/verified (D-02) |
| T-09-06 | Tampering | model directory path handling | mitigate | localModelPath is derived by the caller from the data dir (plan 04), not from untrusted input; verifyManifest reads only manifest-listed relative paths under that root |
