<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backup file at rest -> anyone who obtains it | Portable encrypted backup may be stored anywhere; confidentiality rests on the passphrase |
| adversarial backup file -> restore | An attacker-crafted envelope reaches restore's decrypt + SQLite insert path |
| plaintext export -> disk | The escape hatch writes unencrypted memory to disk by explicit user choice |
| restore --out -> live database | A wrong path could destroy the live DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-17 | Information Disclosure | backup at rest | mitigate | Argon2id at ARGON2ID_REVIEWED_FLOOR + XChaCha20-Poly1305-IETF AEAD (authenticated); cms.backup.v1 domain separation from sync (ADR 0047) — never wrapWithPassphrase |
| T-07-18 | Information Disclosure | plaintext export mistaken for backup | mitigate | Distinct filename/extension, explicit stderr warning, required --plaintext flag unreachable via any backup alias; plaintext never the default |
| T-07-19 | Tampering / DoS | adversarial backup file | mitigate | Zod-validate envelope schema before decrypt; single uniform failure on any AEAD/passphrase error before touching app state (mirror openSyncEnvelope discipline); bound all fields |
| T-07-20 | Tampering (data loss) | restore over live DB | mitigate | Restore only writes a new path; existing --db requires explicit confirmation (source-delete pattern); newer-schema envelope refused |
| T-07-21 | Information Disclosure | key loss / partial write | mitigate | key zeroized in finally; atomic temp+fsync+rename prevents truncated backup files (Pitfall 2); content-free receipt |
| T-07-22 | Spoofing | cross-domain crypto reuse | mitigate | Backup envelope is cryptographically inert against the sync protocol (distinct AAD domain); test asserts non-interoperability both directions |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase (libsodium/zod/node built-ins only) |
</threat_model>
