## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-04 | Elevation of Privilege | consent -> approve | mitigate | Only explicitly-approved sources reach `SourceLifecycleService.approve`; declined sources are skipped before any grant or content read (asserted by test) |
| T-07-05 | Repudiation | grant path | mitigate | Consent drives the existing durable grant/audit path (ADR 0044) rather than a side channel, so every approval is attributable |
| T-07-06 | Information Disclosure | discovery phase | mitigate | Discovery is metadata-first (existing importer behavior); no message content is read before consent |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase |
</threat_model>
