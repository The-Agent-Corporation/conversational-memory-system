<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| release upgrade -> migrate() | New binary opens an older on-disk schema; migration transforms it in place |
| concurrent writers -> schema_migrations | Two processes may open the same file with a pending migration |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-07 | Tampering | migration apply() | mitigate | Each migration + its schema_migrations insert run in one `begin immediate`/`commit`/`rollback`; a throw leaves DB and version untouched (asserted) |
| T-07-08 | Denial of Service | concurrent open race | mitigate | SQLite `begin immediate` serializes writers; the losing writer's whole transaction fails atomically — no double-apply, no UNIQUE corruption (asserted) |
| T-07-09 | Repudiation | schema history | mitigate | `schema_migrations` records version/description/applied_at as an inspectable audit trail (fits REQ-039 ethos); surfaced by the health plan |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase |
</threat_model>
