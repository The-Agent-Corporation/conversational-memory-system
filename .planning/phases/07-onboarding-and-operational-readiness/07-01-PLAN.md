## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| terminal argv -> bin dispatcher | Untrusted subcommand string and passthrough argv cross into module resolution |
| dispatcher -> command module | Passthrough argv is handed to each command's own validated parseArgs (unchanged) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Elevation of Privilege | bin.ts subcommand -> import() | mitigate | Registry is a closed static allow-list keyed by exact name; unknown names are rejected before any import (no dynamic path construction from user input) |
| T-07-02 | Denial of Service | dispatcher error path | mitigate | Top-level `.catch` writes stderr + sets `process.exitCode = 1`; never `process.exit`, never throws unhandled — matches existing command error shape |
| T-07-03 | Tampering | 20-file refactor | mitigate | Change is signature/export/guard-call only; typecheck + each module's existing unit tests (run in per-wave `npm test`) prove run*Command behavior is unchanged |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase (07-RESEARCH.md Package Legitimacy Audit: none proposed); nothing to gate |
</threat_model>
