| Boundary | Description |
|----------|-------------|
| MCP client -> memory_explain | Untrusted agent requests provenance for an arbitrary id under a bounded ProfileAuthority |
| scoped agent vs owner CLI | The MCP tool is scope-restricted; the CLI runs with local-owner authority (may pass --all-scopes) |
| audit-log export -> disk/stdout | Bulk provenance leaves the store; must not carry content |
