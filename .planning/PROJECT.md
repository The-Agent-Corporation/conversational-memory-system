# Universal Personal Memory

## Vision

One continuous, expanding and contracting personal conversation across agent products, with every native history left intact and every recalled fact traceable to its source.

## Current State

The host-neutral canonical timeline, four initial history importers, resumable checkpoints, deterministic historical bootstrap, source lifecycle controls, continuous local daemon, and generic MCP interface are implemented. Phase 5 is complete: Codex, OpenClaw, and other compatible local agents can use the same explicit-profile memory over SDK-backed STDIO through bounded read tools and confirmation-gated atomic mutations. Proposal payload dependencies are authorized recursively and revalidated transactionally before writes. Desktop notifications remain explicitly deferred.

## Product Boundaries

- Native Codex, Claude Code, OpenClaw, and Hermes histories remain read-only.
- Content is read only after an exact source grant is approved.
- Canonical memory contains user/assistant text and compact redacted tool-call events; tool results and system prompts are excluded.
- Memory is assistive context, never authority.
- Person, workspace, client, case, and sensitivity boundaries override universal recall.
- External models are optional adapters, never a local correctness dependency.

## Current Milestone

Zero-Knowledge Multi-Device Sync: research and approve an encrypted convergence protocol without weakening local authority, auditability, deletion, or retrieval isolation.
