# Synthesized Context

The repository began as a Hermes/Roscoe adapter and now contains a host-neutral person timeline, four history import paths, and a resumable historical contraction pipeline. The immediate missing safety layer is source lifecycle management. Continuous rescanning would be unsafe until approvals are durable, revocation stops ingestion, deletions propagate through derived memory, unsupported records are inspectable, and retrieval honors sensitivity boundaries.

The existing `.planning` directory contains requirements and a roadmap but lacks the GSD `PROJECT.md`, `STATE.md`, `config.json`, and phase artifact structure.
