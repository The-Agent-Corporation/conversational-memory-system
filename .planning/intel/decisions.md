# Synthesized Decisions

1. The durable product boundary is one person-scoped canonical conversation timeline.
2. Native history stores remain read-only and source/session boundaries remain provenance.
3. Content access requires approval bound to one canonical root or database.
4. Local storage and deterministic operation remain authoritative and offline-capable.
5. Historical contraction preserves canonical event IDs and requires human review for durable structural proposals.
6. Revocation and deletion must be auditable, reversible where possible, and propagated into derived memory.
7. The daemon may process only durably approved sources.
8. MCP is the generic host interface after safe continuous local operation exists.
9. Zero-knowledge synchronization cannot begin before its threat model and convergence protocol are approved.
10. Durable memory records tool calls as assistant events with the tool name and a bounded, redacted invocation summary; tool-result payloads are never persisted.
