# Synthesized Constraints

- Never mutate native agent history stores.
- Never import content without root-specific approval.
- Never reassign persisted objects across people.
- Never persist raw detected secrets.
- Never make an external model mandatory for deterministic operation or tests.
- Never auto-approve boxes, traces, conclusions, or destructive memory changes.
- Never surface sensitive workspace/client memory into unrelated contexts.
- Never introduce custom cryptographic primitives.
